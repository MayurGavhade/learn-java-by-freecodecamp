Writing a class with a main()

The main() method is where your program starts running.
No matter how big your program is (in other words, no matter how many classesyour program uses), there’s got to be a main() method to get the ball rolling


inside main() methods you can
make statements
make loops
make branching


loop -The key to a loop is the conditional test. In Java, a conditional test is an expression that results in a boolean value—in other words, something that is either true or false

< - less than

> - greater than

== - equality

example

int x = 4;

while(x == 4) {
  inside this code will run
}

while(x > 5) {
 inside this code will not run
}


conditional branching
if test is basically the same as the boolean test in a while loop—except instead of saying, “while there’s still chocolate,” you’ll say, “if there’s still chocolate...”

int x = 20;

if (x == 20) {
  the code will run
} else {
  if condition is not true then this code will run
}


System.out.print vs. System.out.println

System.out.println inserts a newline (think of println as printnewline)

System.out.print keeps printing to the same line. If you want each thing you print out to be on its own line, use println. If you want everything to stick together on one line, use print.

example

System.out.print("Hello" , "World");
output -> Hello World

System.out.println("Hello" , "World");
output -> Hello
          World
